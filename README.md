# TiVoo

**TiVoo** is a mobile-first vertical short-video web application designed for fast, smooth scrolling and interactive short-form content.

## Features
- **Vertical Snap Feed:** Full-screen short video playback with smooth vertical scrolling and auto-play on focus.
- **For You & Following Tabs:** Switch between general discovery and followed creators.
- **Social Interactions:** Like videos, post comments in a slide-up drawer, and share clips.
- **Video Upload Drawer:** Add local videos with custom captions and sound labels.

## Tech Stack
- HTML5, CSS3, and Vanilla JavaScript
- Ready to integrate with Firebase and GitHub Pages
